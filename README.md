# Floating Hamburger Menu

A minimal, animated floating hamburger menu component for websites. Includes:
- Floating circular hamburger icon (`☰`) that toggles to a close icon (`✖`)
- Animated rotation effect
- Vertical submenu with links (e.g., WhatsApp, Contact page)
- Fully responsive and easy to integrate

## 🚀 Demo
Insert this component into any HTML page and see it float at the bottom-right corner.
